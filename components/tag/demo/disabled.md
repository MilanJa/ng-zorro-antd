## zh-CN

设置 `nzDisabled` 后，标签不能再切换选中或关闭，也不应用自定义颜色；禁用外观需要 v6 样式表。`nz-tag` 没有 `href` 与自定义关闭图标输入，因此 antd 示例中的这两个标签未包含在内。

## en-US

Set `nzDisabled` to make the tag unusable: it can no longer be toggled or closed and a custom colour is not applied. The greyed-out look requires the v6 stylesheet. `nz-tag` has no `href` or custom close icon input, so those two tags of the antd demo are left out.
