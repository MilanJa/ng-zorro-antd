## zh-CN

通过 `nzSize` 设置进度条尺寸：预设名称、数字、`[width, height]` 或 `{ width, height }`。圆形和仪表盘只接受数字或预设名称；预设名称不改变圆形画布大小，请使用数字。

## en-US

Set the size with `nzSize`: a preset name, a number, `[width, height]` or `{ width, height }`. Circle and dashboard take a number or a preset name only; a preset name keeps the circle canvas, so use a number to resize it.
