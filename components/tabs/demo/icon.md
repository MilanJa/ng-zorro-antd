## zh-CN

通过 `nzIcon` 为标签添加图标，也可以传入模板，例如第三方图标库的 `<svg>`。模板图标的间距需要 v6 样式表。`nzDefaultActiveKey` 按 `nzKey` 默认选中第二个页签。

## en-US

Set `nzIcon` to give a tab an icon; a template works too, for example a bare `<svg>` from a third-party icon library. The spacing of a template icon requires the v6 stylesheet. `nzDefaultActiveKey` selects the second tab by its `nzKey`.
