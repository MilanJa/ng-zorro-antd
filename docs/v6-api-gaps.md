# Ant Design v6 alignment: API gaps

Limitations met while aligning components with antd v6 that cannot be closed without a public API change
(new input/output, rename, removed feature). Sub-project 3 (API alignment) consumes this list.

| Component             | antd v6 behaviour                                                                                                                                                      | ng-zorro today                                                  | Gap                                     |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------- |
| Popconfirm            | `description` prop                                                                                                                                                     | no `nzPopconfirmDescription`                                    | new input (sub-project 3)               |
| Progress              | `percentPosition`/`size` object                                                                                                                                        | not available                                                   | inputs (sub-project 3)                  |
| Message               | message stacking (`stack`)                                                                                                                                             | not available                                                   | new config                              |
| Notification          | notification stacking (`stack`)                                                                                                                                        | not available                                                   | new config                              |
| Message, Notification | global singletons                                                                                                                                                      | scoped `[nzTheme]` does not reach them                          | documented limit                        |
| FloatButton           | `badge` prop                                                                                                                                                           | `nz-badge` wrapping                                             | badge inside the button (sub-project 3) |
| FloatButton, BackTop  | drag, `content` slot, `showProgress`                                                                                                                                   | not available                                                   | new inputs                              |
| Radio.Group           | `vertical` prop (`ant-radio-group-vertical`)                                                                                                                           | not available                                                   | new input (sub-project 3)               |
| Radio.Group           | `block` prop (`ant-radio-group-block`)                                                                                                                                 | not available                                                   | new input (sub-project 3)               |
| Radio, Radio.Button   | `block` prop (`ant-radio-wrapper-block`, `ant-radio-button-wrapper-block`)                                                                                             | not available                                                   | new input (sub-project 3)               |
| InputNumber           | `mode="spinner"` prop (`ant-input-number-mode-spinner`)                                                                                                                | no `nzMode`; always the "input" layout                          | new input (sub-project 3)               |
| Slider                | draggable range track (`ant-slider-tracks`, `ant-slider-track-draggable`)                                                                                              | no drag-to-move-range feature                                   | new feature (sub-project 3)             |
| Mentions              | `size` prop (`ant-mentions-sm`/`-lg`, `ant-mentions-affix-wrapper-sm/-lg`)                                                                                             | no `nzSize`                                                     | new input (sub-project 3)               |
| Tree                  | `DirectoryTree` (`directory` prop, `ant-tree-directory`)                                                                                                               | no directory-tree mode                                          | new component/mode (sub-project 3)      |
| Tree, TreeSelect      | `showLine.showLeafIcon` (`ant-tree-switcher-leaf-line` connector when off)                                                                                             | line-mode leaf switcher always shows a file icon                | new input (sub-project 3)               |
| DatePicker            | `multiple` prop (`ant-picker-multiple`, `-multiple-input`, `-selection-item*`, `-selection-overflow*`, `-selection-placeholder`)                                       | no `nzMultiple`; always single-value selection                  | new input (sub-project 3)               |
| DatePicker            | `prefix` prop (`ant-picker-prefix`)                                                                                                                                    | no `nzPrefix`; TimePicker has `nzPrefix`, DatePicker does not   | new input (sub-project 3)               |
| DatePicker            | masked-input typing hint (`ant-picker-input-placeholder` modifier on `.ant-picker-input` while a partial value is typed, `@rc-component/picker`'s `Selector/Input.js`) | plain `<input>`, no mask/hint state                             | new feature (sub-project 3)             |
| Transfer              | `selectAllLabels` header dropdown (`ant-transfer-list-header-dropdown`, `Section.js` line 284)                                                                         | no header dropdown; the header only shows the plain count/title | new input + feature (sub-project 3)     |
| Transfer              | `pagination` prop (`ant-transfer-section-with-pagination`, list-level `Pagination`)                                                                                    | no pagination; the list always renders every item               | new input + feature (sub-project 3)     |
